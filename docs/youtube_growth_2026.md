# YouTube ショート／横動画の伸ばし方（2026年10月時点の調査メモ）

調査日：2026-10-17。**公式（YouTube ブログ・ヘルプ・Creator Insider）で確認できたもの**と、**ブログ等の未確認情報**を分けて書く。
数字の「目安」はほぼ全部が非公式なので、YouTube Studio の自分の数字で判断すること。

---

## 1. 収益化（YPP）の条件 ― 最重要

| 項目 | 2027年1月31日まで | **2027年2月1日から（新規申請者）** |
|---|---|---|
| 登録者 | 1,000人 | 1,000人（多くの報道が据え置きとするが、公式文面では明記なし） |
| 横動画ルート | 公開動画の総再生時間 4,000時間／直近12か月 | **8,000時間／直近365日** |
| ショートルート | ショート有効視聴 1,000万回／直近90日 | **2,000万回／直近90日** |
| ショートの広告収益分配 | YPP参加で対象 | **直近90日でショート1,000万回以上のときだけ**（下回ると横動画の収益だけ。超えると自動で復帰） |

- 発表：2026-08-10 YouTube 公式ブログ（2018年以来の大きな改定）。すでに YPP に入っているチャンネルは入口条件の変更の影響を受けない。
- **このチャンネルへの意味**：2027年2月までに 1,000人＋4,000時間 を達成できれば旧条件で入れる。間に合わなければ 8,000時間 が必要。→ ショートで人を集め、**横動画の総再生時間を積む**のが本筋。

## 2. 収益化できないコンテンツ（このチャンネルに直接関係）

公式ポリシー（2025-07-15 に「repetitious content」→「**inauthentic content（オリジナリティのない量産型）**」に改名、2026-07 に説明を明確化）。

**収益化できない例（公式の文言）**
- 「**画像のスライドショー**、テンプレート的な筋書き、スクロールする文字だけで、**ストーリー・解説・教育的価値がほとんどないもの**」
- 「量産された印象を与える、汎用的なテンプレートで作られた AI 生成コンテンツ」
- 自分が作っていない素材の朗読だけ／ほとんどストーリーのない切り抜きの寄せ集め（reused content）
- 感情を煽るだけで筋のない不穏な内容、AI が専門家（医療・法律・金融・政治）を名乗る内容

**収益化できる例（公式の文言）**
- 元の素材に**自分の解説やストーリーを加えたもの**（「元動画とあなたの動画に意味のある違いがあると視聴者に分かること」）
- 映画の場面に、書き直したセリフや別のナレーションを付けたもの
- 毎回同じオープニング／エンディングでも、中身の大部分が毎回違うもの
- AI を台本の推敲や背景素材づくりの「道具」として使うこと

**このチャンネルのリスクと対策**
- 公式の場面写真＋合成音声のナレーションは、作り方を間違えると「画像スライドショー」「量産型」と見なされやすい。審査はチャンネル全体で見られる。
- 対策：
  - **毎回、独自の考察・ストーリーを軸にする**（雑学の羅列や、ネットの文章の読み上げにしない）
  - 動画ごとに構成・見せ方を変える（同じテンプレの使い回しに見せない）
  - 図解・赤丸・比較画面など、**写真の上に自分の編集で意味を足す**
  - 投稿ペースを上げるために中身を薄くしない
  - 可能なら、本人の声や本人の視点（「私はこう考える」）を入れるとさらに強い

## 4. ショートの伸ばし方

**公式に言われていること**
- 新しいショートは、まず「楽しんでくれそうな人たち」に見せて、反応が良ければさらに広がる（YouTube Shorts 担当 Todd Sherman）。「視聴者こそがアルゴリズム」。
- Studio で一番見るべき指標は「**視聴された割合（スワイプされずに見られた割合）**」。
- 投稿時間・1日の本数・ハッシュタグは、アルゴリズム上の決め手ではない（ハッシュタグは必須ではない）。
- 長さは「話を伝えるのに必要な長さで」。最長3分（2024-10〜）。
- ショートと横動画は**別々の仕組みで推薦される**ので、ショートが伸びても横動画が自動で伸びるわけではない → **「関連動画」リンクで本編へ明示的に誘導**する。

**実践（公式＋多数の運用者で一致していること）**
- 最初の1秒で止める：答えのチラ見せ、強い一言、謎（このチャンネルの「〇〇人だった」型）。
- 最後まで見られる・繰り返し見られるほど強い。間を詰める（ジェットカット）。
- 1本1テーマ。結論や続きは本編へ。
- 他人の動画の転載・切り抜きだけはしない（10月の変更で露出が減る）。
- カスタムサムネが使えるようになったので、チャンネル画面・検索で目立つサムネを付ける。

## 5. 横動画の伸ばし方

**公式・ほぼ確実なこと**
- おすすめは「**視聴者の満足**」を最大化するよう作られている。クリック率、視聴時間、アンケート（満足度）、高評価・コメント・共有などを組み合わせて判断し、**単独の指標では決まらない**。
- クリック率だけ高く維持率が低い（釣りサムネ）と、満足度が下がって逆効果。サムネ・タイトルは中身と一致させる。
- サムネ（現在はタイトルも）を「テストと比較」（A/B テスト）機能で比べられる。どれを試せるかは Studio の画面で確認する。

**多くの運用者が一致している実践（非公式）**
- **最初の30秒**で離脱させない：結論の予告、謎の提示、なぜ最後まで見るべきかを言う。
- 公開後 24〜48 時間の反応（CTR・維持率）で広がり方が決まりやすい。
- チャプター、終了画面、カード、再生リストで、次の動画に連れていく（総再生時間＝収益化条件に直結）。
- シリーズ化（同じ型のサムネ・タイトルで続ける）で、2本目以降も見てもらう。
- CTR の目安「4〜6% 普通、7%〜 良い」などの数字はブログ発で公式ではない。

## 6. このチャンネルの方針（調査を踏まえて）

1. **横動画を主力**にして総再生時間を積む（2027-02 以降は 8,000時間 必要）。ショートは入口。
2. ショートは本編の序盤を使った「答えのチラ見せ→謎→関連動画で本編へ」の型。毎回、本編と関連動画リンクをセットで出す。
3. 量産型と見なされないよう、毎回の考察の中身・構成・編集を変える。読み上げ・テンプレ使い回しはしない。
4. サムネは「都市伝説チャンネル型（上下の帯・左右の2文字）」でシリーズ感を出しつつ、**中身と一致**させる。
5. 数字は Studio の「視聴された割合」（ショート）、「最初の30秒の維持率」「CTR」（横動画）を見て改善する。
