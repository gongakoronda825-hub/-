# FACE CHASE

宙に浮かぶ「顔」から逃げ回る3Dブラウザゲーム。捕まったら終わり。
Three.js を `lib/` に同梱しているので、ビルドもインストールも要りません。

## 遊ぶ

ES Modules を使っているため、`index.html` をダブルクリックで開くのではなく、ローカルサーバー経由で開きます。

```sh
cd face-chase
npx serve .            # または: python3 -m http.server 8000
```

表示された URL（例 `http://localhost:3000`）をブラウザで開きます。
スマホで試すときは、同じ Wi-Fi から PC の IP アドレス（例 `http://192.168.x.x:3000`）を開きます。

GitHub Pages では main に入ると `https://gongakoronda825-hub.github.io/-/face-chase/` で公開されます。

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 左下のスティック（左側のどこを触っても出ます） |
| ダッシュ | Shift / Space | 右下の DASH |
| 開始・リトライ | Enter / ボタン | ボタン |
| 音のオン・オフ | M / 右上ボタン | 右上ボタン |

## 顔画像の差し替え

`assets/face.png` を置き換えるだけです。

- 縦横比はそのまま使います（引き伸ばしません）
- 周りの透明な余白や白い背景は、読み込み時に自動で切り取ります
- 画像が見つからないときは、仮の顔で動きます（タイトル画面に注意書きが出ます）

## 構成

```
face-chase/
  index.html          画面の骨組み（HUD・スタート画面・GAME OVER）
  style.css           見た目とレスポンシブ
  game.js             ゲーム本体（3D・操作・敵AI・演出・サウンド）
  lib/three.module.min.js   Three.js r170（MIT, lib/three.LICENSE）
  assets/face.png     追いかけてくる顔
```

## 中身のメモ

- **難易度**：10秒ごとに顔が1体増えます（上限8体）。敵の速度は 1秒あたり +0.03 でゆっくり上がり、上限あり。数値は `game.js` 冒頭の `CONFIG` にまとまっています
- **敵AI**：1m 間隔のグリッドに、プレイヤーからの距離場（ダイクストラ）を作り、敵はそれを下って回り込みます。見通しが通っているときはまっすぐ突っ込み、仲間同士は少し離れます
- **当たり判定**：円 vs 直方体・円柱の押し出し。フィールドの外にも出られません
- **演出**：近づくほど画面が暗くなり、赤く脈打ち、揺れ、WARNING と心音が速くなります。画面外の顔は、画面端のアイコンで方向を示します
- **捕まったとき**：顔が画面いっぱいに迫る → フラッシュ → 「そこそこバっチリ」 → GAME OVER（生存時間とベスト）。ベストは localStorage に保存
- **サウンド**：すべて Web Audio で合成（音源ファイルなし）。iPhone はマナーモード中だと鳴りません
- `?debug` を付けて開くと、コンソールから `__fc` で内部状態を触れます（`__fc.game.invincible = true` など）
