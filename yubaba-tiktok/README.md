# 湯婆婆、実はいい上司（TikTok 縦型動画）

`yubaba_tiktok.mp4` — 1080×1920 / 30fps / 約38.8秒 / H.264 + AAC。BGM なし（TikTok の楽曲ライブラリで後付けする前提）。
[耳をすませば版](../mimi-imax-tiktok/)・[アリエッティ版](../arrietty-imax-tiktok/)と同じ仕組み（フック → 理由3つ → 締め → フォロー誘導）。

## 作り直す

```
pip install pillow
cp <応援する湯婆婆の画像> build/img/yubaba_cheer.jpg
cp <過去動画のサムネイル1> build/img/follow_1.jpg
cp <過去動画のサムネイル2> build/img/follow_2.jpg
./make.sh
```

`build.py` はアリエッティ版と同じもので、締めの呼びかけ（`CTA_TEXT`）を出さない設定と、画像ごとの見せどころ（`FOCUS`）を足してある。
