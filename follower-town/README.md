# 人口0人の街

**TikTokのフォロワー1人 = 街の人口1人。**
フォロワーが増えるほど街が発展していく企画の、第1回ぶん（人口0人）です。

人口が0人ということは、この土地にはまだ人間がひとりもいません。
だから家も道も店も駅も電柱もなく、代わりに恐竜が歩いています。

`index.html` をブラウザで開くだけで動きます。
インストールも通信も不要（外部ライブラリ・CDN・Webフォント・APIを一切使っていません）。

## 見えるもの

- クォータービュー（斜め上から見下ろす）の太古の土地
  草原・森・丘・崖・蛇行する川・池・岩・巨大シダ・木生シダ・ソテツ
- 恐竜4種。竜脚類（大型草食）、剣竜（中型草食）、小型恐竜、翼竜
- 恐竜は歩く・立ち止まる・首を下げて草を食む・走る・空を横切る。
  待機時間も方向も速度も個体ごとにばらばらで、同じ動きになりません
- 雲の影がゆっくり流れ、水面が光り、羽虫が舞う
- カメラは約1分半周期でごくゆっくり漂います（動画撮影で酔わない速さ）

## 画面の演出（開いてから約16秒）

| 時刻 | 起きること |
|---|---|
| 0.0s | 太古の世界がフェードイン |
| 0.2s | 「人口 0人」「時代：人類誕生前」「フォロワー 0人」 |
| 3.6s | 「この街には、まだ誰も住んでいません。」 |
| 8.6s | 翼竜が画面を横切る |
| 13.4s | 「1人目の住民を待っています。」 |
| 15.6s | 右下に「もう一度」 |

TikTokの縦画面（9:16）で撮ることを前提にしたレイアウトです。
画面録画して、そのまま投稿できます。

## 人口を変える

`src/config.js` の `POPULATION` を書き換えると時代が変わります。

```js
FT.config.POPULATION = 0;  // 人類誕生前（恐竜時代）
```

URLでも上書きできます。動作確認用です。

```
index.html?pop=1        → 縄文
index.html?pop=3000     → 江戸
index.html?seed=7       → 別の土地を生成
```

**注意：今回実装したのは「人口0人（恐竜時代）」の風景だけです。**
人口を1以上にすると時代表示だけが変わり、風景は恐竜時代のまま出ます
（コンソールに未実装の警告が出ます）。

## 時代のテーブル

`src/data/eras.js` に全時代を定義してあります。判定は `FT.eras.getEra(population)`。

| 人口 | 時代 | 世界観 |
|---|---|---|
| 0 | 人類誕生前 | 恐竜時代 |
| 1〜10 | 縄文 | 小さな原始集落 |
| 11〜50 | 弥生 | 稲作を始めた村 |
| 51〜100 | 古墳 | 共同体が発展 |
| 101〜300 | 奈良 | 寺・市場が生まれる |
| 301〜500 | 平安 | 屋敷・庭園・文化 |
| 501〜1,000 | 鎌倉 | 武家・城・城下町 |
| 1,001〜2,000 | 室町 | 商業都市 |
| 2,001〜3,000 | 江戸 | 大規模な城下町 |
| 3,001〜5,000 | 明治 | 鉄道・学校・近代化 |
| 5,001〜7,000 | 大正 | 百貨店・映画館・路面電車 |
| 7,001〜10,000 | 昭和 | 商店街・駅・工場・自動車 |

各時代には、将来その街に建つものを `buildings` / `infrastructure` / `jobs` / `life`
として書いてあります。つまり次の順で街が生えるように作ってあります。

```
population → era → buildings → infrastructure → residents → daily life
```

## 構成

```
follower-town/
├── index.html          ← これを開く
├── style.css           ← UI（人口・時代・字幕）
└── src/
    ├── config.js       ← 人口・フォロワー数・密度などの設定
    ├── data/eras.js    ← 時代テーブルと getEra()
    ├── core/
    │   ├── rng.js      ← シード付き乱数とノイズ
    │   ├── pixel.js    ← ドット絵の描画道具（円柱シェーディング・輪郭線）
    │   └── display.js  ← 内部解像度とリサイズ
    ├── world/
    │   ├── terrain.js  ← 地形生成とタイルの焼き込み
    │   └── props.js    ← 木・シダ・岩・雲の影
    ├── life/
    │   ├── species.js  ← 恐竜の体と全フレームの生成
    │   └── agents.js   ← 恐竜のふるまい（徘徊・採食・走行）
    ├── scene/director.js ← 演出の台本
    └── main.js         ← 起動と毎フレームの組み立て
```

素材ファイルは1枚もありません。地形も植物も恐竜も、起動時にコードから描いています。
シードを固定しているので、何度開いても同じ土地・同じ絵になります。

### データと描画の分離

- **データ**：`data/eras.js`（時代）、`config.js`（人口・密度）
- **生成**：`world/`（地形・植物）、`life/species.js`（恐竜の見た目）
- **ふるまい**：`life/agents.js`
- **演出**：`scene/director.js`

新しい時代を足すときは、`eras.js` に行を足し、その `scene` に対応する
世界の組み立て（`world/` 配下）を1本書けば済むようにしてあります。

## 描き方のメモ

ドット絵はすべて「パレット番号の2次元配列」を組み立ててから、
1ドット=1pxのキャンバスに焼いています。アンチエイリアスが一切かからないので、
スマホで拡大表示してもドットが濁りません。

恐竜は骨（折れ線）と太さだけを与えて、光源（左上）に対する円柱の向きで
明暗を選んでいます。同じ体から「歩く」「首を下げる」ポーズが生えるので、
種類ごとに何十枚も手で描かずに済みます。

地形の色はタイル単位ではなく、隣のタイルと補間した値＋画素ごとのディザで
決めています。マス目が見えない草原にするためです。
高さの段の境目にはわざとノイズを入れて、等高線が画面を横切る長い直線に
ならないようにしています（これをやらないと、畑のうねのように見えます）。
