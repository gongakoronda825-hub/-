# 耳をすませば IMAX 告知（TikTok 縦型動画）

`mimi_imax_tiktok.mp4` — 1080×1920 / 30fps / 約33秒 / H.264 + AAC。BGM なし（TikTok の楽曲ライブラリで後付けする前提）。

## 作り直す

```
pip install pillow
cp <IMAX版ポスター画像> build/img/imax_poster.jpg
./make.sh
```

- 台本（テロップ・ラベル・字幕・読み・使う画像）は `script.py`。字幕の表示と読み上げ用の読み（「IMAX」→「アイマックス」、「4K」→「ヨンケー」）を分けて持ち、`*〜*` で囲んだ部分は黄色で強調する
- `tts.py` が VOICEVOX（青山龍星・ノーマル、話速 1.15）でシーンごとに合成し、モーラ長から字幕の出るタイミングを決める。エンジンは `make.sh` が docker で起動する
- 効果音は効果音ラボの定番素材: 冒頭「シャキーン」(shakin1)、場面転換「シュッ」(sceneswitch1)、画像切り替え (slide1)、締め「キラーン」(kira1)。再配布禁止のため `make.sh` が取ってくる

### クレジット

VOICEVOX の規約により、動画内（画像の右上）に「VOICEVOX:青山龍星」と入れている。TikTok の説明文にも書いておくとよい。
- `build.py` がシーンの長さをナレーションに合わせて決め、フレームを PIL で描いて ffmpeg に流す
  - 横長の写真は横幅いっぱい・縦1000pxで大きく見せ、上下は背景ぼかし。写真の中で Ken Burns（ズーム＋パン）。縦長のポスターは角丸カードでゆっくり寄り、字幕はロゴにかぶらないよう下に出す
  - テロップ: M PLUS Rounded 1c Black、白＋黄色強調、太い黒フチと影。「理由 1」などのラベルが左からすべり込み、テロップは弾むように出る
  - 字幕: M PLUS Rounded 1c ExtraBold、区切りごとに小さく弾んで出る
  - 冒頭は0フレーム目からテロップが出ている。最後は暗転せずループで冒頭に戻れる。締めのシーンへはフラッシュなしのゆっくりしたクロスフェード
  - TikTok の UI（上端・下端・右の操作ボタン）にかからない位置に配置。音量は -14 LUFS
