# 耳をすませば IMAX 告知（TikTok 縦型動画）

`mimi_imax_tiktok.mp4` — 1080×1920 / 30fps / 36秒 / H.264 + AAC。BGM なし（TikTok の楽曲ライブラリで後付けする前提）。

## 作り直す

```
pip install edge-tts numpy pillow
./make.sh
```

- 台本（テロップ・字幕・読み・使う画像）は `script.py`。字幕の表示と読み上げ用の読み（「IMAX」→「アイマックス」、「4K」→「ヨンケー」など）を分けて持っている
- `tts.py` が edge-tts（ja-JP-NanamiNeural, 話速 +40%）でシーンごとに合成し、単語境界から字幕の出るタイミングを決める
- `sfx.py` が効果音（転換の「シュッ」、テロップの「ポンッ」、冒頭の「ドンッ」、締めの「キラーン」）を合成する。外部素材は使っていない
- `build.py` がシーンの長さをナレーションに合わせて決め、背景ぼかし＋中央配置＋Ken Burns のフレームを描いて ffmpeg に流し、テロップと字幕を焼き込む。音量は -14 LUFS に揃える

## 使った画像（すべて https://www.ghibli.jp/works/mimi/ の場面写真）

| 3 | 地球屋の内装／夕焼け | mimi012 → mimi021 | 店内のバロン、西日の差す店内。夕焼け空単体のカットはない |
