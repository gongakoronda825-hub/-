# 舞台『千と千尋の神隠し』ワールドツアー TikTok動画 要件定義

参照: https://www.tohostage.com/spirited_away/

## 1. 基本要件

| 項目 | 内容 |
|---|---|
| 尺 | 約18秒（冒頭の舞台映像 3.3秒 ＋ 本編 14.8秒） |
| 画面 | 縦 9:16 / 1080×1920 / 30fps |
| 音 | **音楽（BGM）は使わない**。効果音・環境音は使う（作品の世界の音で雰囲気をつくる）。冒頭の舞台映像だけは元の音をそのまま使う |
| 必須素材 | ① ワールドツアーのポスター（縦長） ② introduction 画像（黒背景・横長） |
| 目的 | **「ジブリの舞台が日本で観られる」を最初の1秒で伝え**、アカウントをフォローしてもらう |
| ターゲット | ジブリ好き・舞台好き・国内4都市と海外公演を気にしている人 |

## 2. 音と文字の考え方

- BGMがない分、**効果音で場面の切り替わりとテンポをつくる**。音は作品に出てくるもの（水・電車・湯屋）から選ぶ
- 音を消して見る人も多いので、**文字だけでも話が分かる**ようにする。1カットに1メッセージ、大きい文字で
- 文字は 1行14文字以内、表示は最低1.5秒（読み切れる長さ）
- 動きで間を持たせる：ゆっくりズーム、横パン、1行ずつフェードイン
- TikTokのUIに文字が隠れないよう、上150px・下350px・右120pxには文字を置かない

## 3. 素材の使い方

- **ポスター**（約1056×1504、縦長）：9:16に置くと上下が余るので、同じポスターをぼかして拡大した背景で埋める。
  寄り（千尋のシルエット・ハク）、日程部分、ロゴ部分と、**切り出す場所を変えて何度も使う**
- **introduction 画像**（約1158×668、横長・黒背景）：背景が黒なので、黒の画面の中央に置くだけで縦画面になじむ。
  3行の文字を上から1行ずつ見せる（マスクで隠して順に出す）

## 4. 構成（約18秒）

**方針：最初のフレームで「累計90万人の千と千尋の舞台が帰ってきた」を見せ、弱い場面は短く削る。**

| # | 秒 | 映像 | 画面テキスト | 動き | 音 |
|---|---|---|---|---|---|
| 1 | 0.0–3.3 | 舞台映像：出演者が手をつないで挙げ、一礼するカーテンコール（映像は画面の下寄り） | **0フレーム目から**上の余白に「累計動員 90万人突破」／「千と千尋の神隠しの／舞台が帰ってくる！」 | 千尋を中心に左右へ少しパン | **元の映像の音をそのまま使う** |
| 2 | 3.3–4.8 | ポスターの東京の日程 | 「2027.3〜5 東京 明治座」 | 寄った状態から戻る | 「シュッ」＋「ドン」 |

| 4 | 6.8–9.3 | introduction 画像（黒背景、横幅いっぱい） | （画像内の文字） | 3行を0.5秒おきに出す | 風鈴 → 1行ごとに「ドン」 |

### 最初の画面テキスト（候補）

どれも「ジブリ」「千と千尋」「舞台」「日本」の4つが1秒で読める長さにしている。投稿を分けて比べてもよい。

1. 「千と千尋の神隠しの舞台が帰ってきた」（採用）
1. 「ジブリ『千と千尋』の舞台、日本でやります」
2. 「千と千尋が舞台に。日本公演決定」
3. 「実写じゃない。舞台の『千と千尋』が日本に来る」

### 音の調整
- 0.0秒の「ドン」で、音を出して見ている人の指を止める。最初に静かな間はつくらない
- 音量の目安：大きな音（「ドン」、水しぶき）を一番上にして、電車の音はその半分くらいで下に敷く
- 最後の「ポチャン」で静かに終わり、ループすると冒頭の「ドン」につながる
- ナレーションは入れない（文字と効果音だけで見せる）。入れる場合は、画面の文字をそのまま読む短い声にとどめる
- 効果音は商用利用できる素材（効果音ラボ、TikTok内の効果音など）から選ぶ。映画の音声は使わない

### 動員数の出典

「累計動員90万人突破」は、2026年6月のワールドツアー発表時の公式発表による（2022年の帝劇初演から2026年3月のソウル公演千穐楽までで、上演491回・動員90万名突破）。
2024年のロンドン公演だけなら約30万人。台北公演中に100万人を突破する見込みとされているので、突破が発表されたら「100万人」に更新する。

## 6. 注意点

- 画像はどちらも公式の宣伝素材で、権利は東宝・スタジオジブリ側にある。投稿前に使ってよい範囲（公式の宣伝素材の利用ルール）を確認する
- 日程・劇場名はポスターの記載どおりに書き、公開前に公式サイトで最新情報と照らし合わせる
- 「日本演劇史上最大の海外動員へ」は公式の文言なので、画像のまま見せ、言い換えて誇張しない

### 最後の呼びかけ（フォローのお願い）について

「ジブリの最新情報が知りたい方は是非フォローお願いします」という文言そのものは、作品名・スタジオ名を紹介のために使っているだけなので、
それだけで法律に触れるものではない。ただし次の2点に気をつける（法的な判断が必要なら専門家に確認する）。

- **公式アカウントと誤解させない**：「ジブリの最新情報」を発信する、と言うと公式・関係者と受け取られるおそれがある。
  プロフィールとキャプションに「非公式のファンアカウント」と書き、アカウント名・アイコンにジブリのロゴや公式画像を使わない
- **公式素材の使用はフォローのお願いで重くなる**：この動画はポスター・introduction 画像・舞台映像が中心で、
  日本の著作権法の「引用」には当たりにくい。フォロー獲得（アカウントの宣伝）に使うと、宣伝素材の範囲を超えた利用と見られやすい。
  公式の利用ルールを確認し、特に画面録画した舞台映像は、元の投稿者・権利者が転載を認めているかを確かめる

## 7. 決めておきたいこと

- ナレーションを入れるか（案では入れない）
- 読ませる文字を日本語だけにするか、英語も並べるか（海外公演も見せるなら英語併記が効く）
- 最後の誘導先（公式サイト／プロフィールのリンク）

## 8. 書き出し

完成動画：`spirited_away_tiktok.mp4`（1080×1920 / 30fps / 21秒 / H.264 + AAC）。
公式画像を含むため、動画ファイルはリポジトリには入れていない。

作り直す手順（Python 3。`pip install pillow numpy scipy imageio-ffmpeg`）：

```
python3 sfx.py sfx.wav                    # 効果音を合成（音楽なし）
# 舞台映像を 30fps のコマにする（録画の最初0.35秒に映る再生画面の表示と、下端の再生バーを除く）
ffmpeg -ss 0.35 -t 3.3 -i ScreenRecording.mov -an -vf "crop=1772:826:0:0,fps=30" -q:v 2 clip/c_%03d.jpg
python3 render.py poster.jpg intro.jpg clip <フォントのフォルダ> sfx.wav main.mp4
# 冒頭の舞台映像（音あり）をコマと音声に分けてから、本編の前につなげる
ffmpeg -i Opening.mov -an -vf fps=30 -q:v 2 open/o_%03d.jpg
ffmpeg -i Opening.mov -vn -ac 2 -ar 48000 open.wav
python3 render.py poster.jpg intro.jpg clip <フォントのフォルダ> sfx.wav hook.png   # 冒頭に重ねる文字
python3 opening.py open open.wav hook.png main.mp4 spirited_away_tiktok.mp4
```

- `poster.jpg`：ワールドツアーのポスター（1056×1504）、`intro.jpg`：introduction 画像（1158×668）
- フォント：Noto Sans CJK JP（Black / Bold）、Noto Serif CJK JP（Black）
- 末尾に `0,2.2,8.5` のように秒数を渡すと、その時刻の静止画だけを書き出して確認できる
- 9.5〜14秒は、海外公演の場面 → 舞台写真3枚 → 舞台映像（カーテンコール）の順に差し替えてきた
