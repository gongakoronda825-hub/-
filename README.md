# あそびば

つくったゲームを、すぐ遊んでもらえる場所。ゲーム版の YouTube です。

**https://gongakoronda825-hub.github.io/-/**

個人がつくったブラウザゲームを1か所に並べて、フィードから見つけて、その場で遊べる
ようにするサイト。審査も開発者登録もありません。HTML が1枚あれば載ります。

| YouTube | あそびば |
|---|---|
| 動画を投稿 | ゲームを投稿 |
| 動画を見る | ゲームを遊ぶ |
| 再生回数 | プレイ回数 |
| 高評価 | いいね |
| チャンネル登録 | フォロー |
| おすすめ動画 | おすすめゲーム |
| YouTuber | ゲームクリエイター |

## 画面

| ファイル | 何の画面か |
|---|---|
| `index.html` | フィード。検索・カテゴリ・並び替え・最近遊んだゲーム |
| `game.html?id=…` | ゲームの詳細。いいね、フォロー、操作説明、次に遊ぶ |
| `play.html?id=…` | プレイ画面。全画面の iframe とプレイ数の計上 |
| `creator.html?id=…` | クリエイターのページ。作品一覧とフォロワー数 |
| `upload.html` | 投稿。HTML を選ぶ → その場で試遊 → 掲載する |

## ゲームを追加する

`upload.html` を開いて HTML を選ぶと、その場で試遊できて、下の1〜4の手順と
貼るだけのカタログ記述が生成されます。手で足すときも同じです。

1. ゲームの HTML を `games/<id>/index.html` に置く
2. 16:9 のサムネイルを `assets/img/thumb-<id>.png` に置く（無ければ頭文字のタイルが出ます）
3. `data/catalog.js` の `games` 配列に1件足す
4. コミットしてプッシュ

`data/catalog.js` がサイトの唯一の情報源です。ここに足せば、フィード・検索・カテゴリ・
おすすめ・クリエイターページのすべてに反映されます。はじめての人は、同じファイルの
`creators` 配列に自分の項目も足してください。

投稿ページの「この端末に追加」は、ブラウザの中だけに保存される下書きです。自分の
フィードにはすぐ並びますが、ほかの人には見えません。公開するには上の手順が要ります。

## 反応の記録について

プレイ数・いいね・フォローは、いまのところ**閲覧している端末の localStorage にだけ**
記録されます。サーバーがないので、他の人の数字とは合算されません。初期値の水増しは
していないので、どのゲームも 0 から始まります。

読み書きは `assets/js/store.js` に閉じてあります。画面側のコードは localStorage を
直接触らず、すべて Promise を返すメソッド越しに読みます。サーバーを立てるときは、
このファイルの中身を `fetch` に差し替えるだけで済みます。

## 中身

```
index.html  game.html  play.html  creator.html  upload.html
data/catalog.js        掲載ゲームとクリエイターの定義
assets/css/app.css     配色トークン、ヘッダー、カード、各画面
assets/js/store.js     反応の保管庫（localStorage、差し替え可能）
assets/js/ui.js        整形・カタログ検索・カード描画・テーマ
assets/js/*.js         画面ごとのスクリプト
assets/img/            サムネイル
games/                 掲載しているゲームの実体
```

ビルドは要りません。素の HTML と CSS と JavaScript だけで、外部ライブラリも
使っていません。スクリプトは `<script src>` で読む昔ながらの形にしてあるので、
サーバーを立てずに `index.html` を直接開いても動きます。

手元で確認するときは、`fetch` を使う場面はありませんが、相対パスの都合上
簡単なサーバーを立てるのが確実です。

```
python3 -m http.server 8000
```

配色は端末の設定（ライト／ダーク）に従い、ヘッダーの月／太陽のボタンで手動でも
切り替えられます。
