# 究極の選択 — ULTIMATE CHOICE

ドット絵RPG風「究極の選択」1シーン。悪魔の取引に乗るか断るかで結末が分岐する、
ブラウザで動く1ファイル完結のゲームです。

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部ライブラリなし）。

## 操作

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 選択肢を移動 |
| Z / Enter / Space | 決定・テキスト送り |

タッチ端末では画面下のボタンで操作できます。

## 中身

- Canvas 2D、内部解像度 256x224 を整数倍に拡大（`image-rendering: pixelated`）
- キャラクターは2次元配列で 1ドット=8px として定義し、拡大描画
- 16色の限定パレット。背景は暗い洞窟／夜のタワマン夜景をコードで生成
- RPGツクール風メッセージウィンドウ、タイプライター表示、点滅カーソル
- ピクセル日本語フォントを CDN から読込（失敗時は monospace にフォールバック）
- 効果音は Web Audio でビープ生成（BGMなし）

## 分岐

- **ルートA「10億円もらう」** → 3年後のタワマン最上階へ。BAD END「10億円と、空っぽの夜」
- **ルートB「ことわる」** → 悪魔は静かに消える。TRUE END「値札のつかないもの」

セリフごとに表示速度を変え、ルートAの「心は、満たされなかった。」は1文字ずつ極端に遅く（スキップ不可）、
ルートBの「お前で3人目だ」の直後には1.5秒の無音・無演出の「間」を置いています。
この「間」が演出の肝です。
