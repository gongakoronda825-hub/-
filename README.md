# 究極の選択

悪魔に取引を持ちかけられる、ドット絵RPG風の1シーン。ブラウザだけで動きます。

導入はギャグ、選択のあとはシリアスに落ちる。その温度差が主題です。結末は2つ。

## 遊ぶ

`index.html` を開くだけです。インストールも通信も要りません。

- **↑ ↓** えらぶ／**Z** または **Enter** けってい
- スマホは画面タップ、または下の ▲ ▼ けってい ボタン

## 中身

外部ライブラリなしの1ファイル完結（HTML / CSS / JS すべてインライン）。

- 256×224 のバッファに Canvas 2D で描画し、整数倍に拡大表示
- キャラクターは「1文字 = 1ドット」の2次元配列を 1ドット8px で拡大描画
- 16色の固定パレット。背景（洞窟・夜景）はシード付き擬似乱数で手続き生成
- 効果音は Web Audio で生成

### 演出について

台詞の表示速度は一律ではなく、行ごとに変えてあります。ギャグ部分は1文字25msほど、
終盤の独白は80〜160ms、そして最後の1行だけ1文字364ms。句読点と三点リーダには
別途の待ち時間が乗ります。

もう一方のルートには、1.5秒だけ何も起きない沈黙があります。**この「間」が演出の中心**なので、
速度を揃える変更を加えるときは、そこだけは触らないでください。
