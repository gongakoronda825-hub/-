# ピンポンダッシュ

スマホの横画面で遊ぶ、一人称の3Dバカゲー。日本の住宅街でインターホンを鳴らして逃げる。

鳴らすほどポイントは増えるが、街の危険度も上がって住民が出てくる。出てきたら、
道と路地と物陰を使って視線を切る。捕まるか、見られ続けるとおしまい。

**これはプロトタイプです。** 見た目より先に「もう一回ピンポンしたい」と思えるかを
確かめるために作ってあり、数値はすべて仮です（→ [数値の調整](#数値の調整)）。

## 遊ぶ

**https://gongakoronda825-hub.github.io/-/pinpon-dash/play/**

インストールも登録も要りません。スマホは横向きにしてください。

配信しているのは `play/index.html` の1枚だけです。外部への通信がまったく無い
（three.js も効果音も全部この中）ので、ダウンロードしてオフラインで開いても
同じように動きます。

開発するときは Vite の開発サーバーを使います。

```
npm install
npm run dev      # vite --host。表示された http://192.168.x.x:5173 にスマホからアクセスする
```

実機での確認が前提です。DevTools のモバイルエミュレーションは、マルチタッチの
挙動が実機と違います。

## 操作

| したいこと | 操作 |
|---|---|
| 移動 | 画面左下のスティック（左半分ならどこを触っても効く） |
| 見まわす | 画面右半分をなぞる。上下は ±85° で止まる |
| ダッシュ | 右下の「ダッシュ」を押しっぱなし。スタミナを使う |
| ピンポン | 門に近づくと出る「ピンポン」を押す。押した瞬間に鳴る |

PC で確認するとき用に、WASD／矢印キーでの移動、マウスドラッグでの視点操作、
Shift でダッシュ、Space または E でピンポンも受け付けます。

右上の数値表示は調整用です。タップすると薄くなります。

## ルール

**ピンポンすると、ポイントが入って危険度が上がります。** 危険度が高いほど1回の
ポイントは大きく（10 → 300pt）、そのぶん住民が出てくる確率も上がります。
危険度は最後に鳴らしてから4秒たつと、少しずつ下がりはじめます。

**住民は3種類。** ふつうの住民はすぐ息が切れますが、おこりんぼはしつこく、
ヤバいひとは視野が広く、見失ってもあたりを捜し回ります。危険度が高いほど
後ろの2種が出やすくなります。

**追ってきた住民をまくとボーナス。** 相手が危険なほど大きい（50 / 100 / 200pt）ので、
「わざと危ない橋を渡る」ことに意味があります。

**ゲームオーバーは2つ。** 追跡中の住民に捕まるか、視認ゲージが満タンになるか。
見られた瞬間に終わりではありません。ふつうの住民なら目の前で約3秒、遠ければ
もっと長くかかります。塀や車の陰に入ればゲージは下がります。

**塀は越えられません。** ジャンプもよじ登りもありません。逃げ道は道路・路地・
曲がり角・遮蔽物だけです。

## 数値の調整

**バランスに関わる数値は `src/core/config.ts` と `src/residents/residentTypes.ts`
の2つだけに置いてあります。** 他のファイルに生の数値を書き足さないでください。

いじる場所の見当:

| 調整したいこと | 触る場所 |
|---|---|
| ポイントの伸び方、住民の出やすさ | `config.ts` の `DANGER_TIERS`（段の追加・削除もここ） |
| 危険度の上がり方・下がり方 | `config.ts` の `DANGER_PER_PING` / `DANGER_DECAY` |
| 逃げ切りやすさ | `residentTypes.ts` の `chaseStamina`（追いかけ続けられる合計時間） |
| 見つかってからの猶予 | `residentTypes.ts` の `gaugeUp`、`config.ts` の `WATCH_RATE_*` |
| 走れる時間 | `config.ts` の `STAMINA_*` |
| 街の形 | `src/town/layout.ts` の `TOWN_MAP`（文字を並べただけの地図） |

まず見てほしいところ:

- **`DANGER_PER_PING`（初期値 9）** が1回のプレイの長さをほぼ決めます。今は
  10回ちょっと鳴らすと最高段に届く速さです。長く遊ばせたいならここを下げます。
- **`chaseStamina`** を伸ばすと一気に殺伐とします。ふつうの住民の 5秒 は
  「鳴らして走れば必ず逃げ切れる」ための値です。
- **`DOORBELL_RANGE`（3m）** を広げると、門に寄らずに鳴らせてしまい、
  緊張感が消えます。

## 中身

Three.js + TypeScript + Vite。物理エンジンは使いません。

```
src/
├── main.ts                      組み立てとゲームループ
├── core/config.ts               ★バランス調整値（ほぼ全部ここ）
├── core/GameState.ts            スコアと危険度
├── core/Renderer.ts             シーン / カメラ / ライト / フォグ
├── core/rng.ts                  シード付き擬似乱数
├── town/layout.ts               ★街の地図（文字の並び）
├── town/Town.ts                 地図 → メッシュ・当たり判定・家の一覧
├── town/MeshBuilder.ts          静的な形を1メッシュに結合する道具
├── town/palette.ts              街の色
├── physics/Collision.ts         円 × 箱の当たり判定と、線分による視線判定
├── player/Player.ts             移動・ダッシュ・スタミナ
├── player/FirstPersonCamera.ts  一人称カメラ
├── input/                       スティック / 視点 / ボタン
├── doorbell/DoorbellSystem.ts   ピンポンの判定と、住民を出す抽選
├── residents/residentTypes.ts   ★住民3種の性能
├── residents/Resident.ts        住民AI（6状態）と視認ゲージ
├── residents/ResidentManager.ts 出現・更新・撤収
├── residents/models/            デフォルメした箱の人モデル
├── audio/Sfx.ts                 Web Audio で作る効果音
└── ui/                          HUD / タイトル / 結果 / 調整用の数値表示
```

### あとから触るときに知っておくとよいこと

**街は文字の地図から組み立てます。** `layout.ts` の `TOWN_MAP` は1文字が
10m四方の区画で、`h` が家、`.` が道路、`,` が路地です。家は必ず道路に面した側に
門とインターホンが付き、面していない家があると例外で落ちます。
**行き止まりと回り道（ループ）を混ぜること**が大事で、一本道にすると
「足の速い方が勝つ」だけのゲームになります。

**街の見た目は全部で1メッシュです。** 家1軒ごとに Mesh を作るとドローコールが
数百になってスマホで落ちるので、`MeshBuilder` にいったん形を溜めて結合しています。
色はマテリアルではなく頂点カラーで持つので、色数を増やしてもマテリアルは1つのまま。
**結合後は個別に動かせない**ので、動くもの（住民・光るインターホンのボタン）は
別のメッシュにしてあります。

**当たり判定も視線判定も XZ 平面の2次元です。** 街は平らで、遮蔽物は全部
軸に沿った箱なので、高さを持つ意味がありません。箱は `solid`（通れない）と
`opaque`（見通せない）を別々に持ちます。電柱は「ぶつかるが視線は通る」、
生け垣は「ぶつかって視線も切る」。この2つを分けているのが逃走の手触りを作ります。

**追跡は「今いる場所」ではなく「最後に見た場所」へ向かいます。** ここが
このゲームの心臓部で、だから角を曲がると振り切れます。プレイヤーの現在位置へ
まっすぐ向かう実装にすると、逃走がただの徒競走になって全部が壊れます。

**住民は経路探索を持ちません。** 目標の方向から ±30° → ±60° → ±90° と
角度をずらして、空いている向きを探すだけです。道が格子状なのでこれで足ります。
完全ではありませんが、見た目には「塀を回り込んできた」ように見えます。

**住民は玄関から出てきます（門ではなく）。** 玄関から門までの 3.4m
（`Town.ts` の `FRONT_YARD`）が、そのまま「鳴らしてから逃げ出すまでの猶予」です。
ここを 0 にすると、鳴らした指の真横に住民が湧いて何もできずに捕まります。

**住民は「見えている限り追う」が、`chaseStamina` を使い切ると諦めます。**
見失ってからの諦めタイマー（`chaseTime`）だけにすると、目の前にいるのに
急に帰りはじめる妙な動きになります。逆に息切れが無いと、スタミナの切れた
プレイヤーは永久に追い回されて逃げ切れません。

**危険度は追われている間は下がりません。** 逃げ切ってから下がりはじめます
（`DANGER_FREEZE_WHILE_CHASED`）。追跡中に勝手に安全になっていくと、
「逃げ切った」という手応えが消えます。

**街の小物はシード付き乱数で置いています。** 毎回まったく同じ街になるので、
「この路地は逃げやすい」「この道は行き止まり」をプレイヤーが覚えられます。
住民の判断のような「毎回違ってよい」ところでは `Math.random()` を使っています。

## いま扱っていないもの

セーブ（ハイスコアだけ localStorage）／ 時間帯・天候 ／ BGM ／ 住民同士の連携や
無線での通報 ／ アイテム・変装 ／ 隠れる操作（しゃがむ・物陰に入るコマンド）／
複数の街 ／ ランキング ／ チュートリアル以上の導線 ／ 住民の経路探索 ／
プレイヤーと住民の押し合い。
