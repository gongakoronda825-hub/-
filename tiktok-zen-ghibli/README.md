# 「禅とジブリ」京都展 ナレーション音声

TikTok用の日本語ナレーション音声と、その生成スクリプト。

## 成果物

| ファイル | 中身 |
| --- | --- |
| `zen-ghibli-tiktok-alpha.webm` | **背景が透明**の縦動画 1080x1920 / 30fps / 1分8秒（VP9 + アルファ） |
| `zen-ghibli-tiktok.mp4` | 同じ内容で背景が緑一色のMP4。スマホで編集するならこちら |
| `zen-ghibli-narration.mp3` | ナレーションのみ MP3 192kbps / 44.1kHz / モノラル |
| `zen-ghibli-narration.wav` | ナレーションのみ WAV 16bit / 24kHz / モノラル |
| `zen-ghibli-subtitles.srt` | 画面に出る文字のタイムコード（フック1枚＋字幕29枚） |

音声はピーク -1.5 dBFS、平均 -16.3 dBFS に整えてあるので、TikTokに載せても
音量が埋もれない。

## 2種類ある理由

同じ絵を、背景の持ち方だけ変えて2本書き出している。

| | 透明版 `.webm` | 緑版 `.mp4` |
| --- | --- | --- |
| 背景 | アルファチャンネルで透明 | クロマキー用の緑 rgb(0, 177, 64) |
| 下ごしらえ | 重ねるだけ | クロマキーで緑を抜く |
| 縁の見え方 | 文字の縁がそのまま残る | 設定次第でうっすら緑が残ることがある |
| 使えるところ | パソコンの編集ソフト（DaVinci、CapCutデスクトップなど） | ほぼどこでも。iPhoneの写真アプリ・CapCutモバイルもOK |

**iPhoneで編集するなら緑版を使う。** iOSの写真アプリとSafariはWebMの
アルファを扱えないため、透明版は取り込めない。iPhone向けの透明動画は
HEVC+アルファ（Apple独自）が必要で、この環境のffmpegでは作れない。

パソコンの編集ソフトで別形式のアルファ付き動画が要る場合は、
QuickTime Animation（`-c:v qtrle`）や ProRes 4444（`-c:v prores_ks
-pix_fmt yuva444p10le`）でも書き出せる。どちらも数百MBになる。

## 動画の作り

- 冒頭2.7秒は **「君たちはどう生きるか」** のフックだけを大きく出す（112px・金色）。
  同じ声で読み上げ、効果音も乗せている。本文の1行目が始まるところで
  字幕に切り替わる
- 字幕とフック以外は何も置いていないので、敷いた画像とぶつからない
- 半透明の影やフェードは使っていない。緑版でキーを抜いたときに縁が
  濁らないよう、文字は不透明の白＋濃い縁取りだけで作っている
- 字幕は画面のやや上寄り（中心 y=1010）、幅は860pxまで。TikTokの
  下のキャプション欄と右のボタン列を避けた位置
- 読み終えた文字が金色 rgb(255, 210, 74) に変わる。声と文字が一緒に
  進むので、音を消して見ている人にもリズムが伝わる
- 字幕の出はじめに軽く弾む動き（0.2秒）。文の切れ目で字幕を送るので、
  1枚あたり平均2.3秒
- 折り返しは「カタカナ語」「鍵括弧の題名」「日付」を割らず、助詞の
  切れ目を選ぶ。1行に収まらないときだけ2行にして、字を少し小さくする

### 緑版でキーを抜く（CapCutなど）

1. 背景にしたい画像・映像を下のレイヤーに置く
2. この `zen-ghibli-tiktok.mp4` を上のレイヤーに重ねる
3. 「クロマキー」で緑の部分をスポイトで選び、強度を上げる
4. 縁に緑が残るときは「シャドウ」「エッジ」のスライダーを少し上げる

緑を別の色にしたい、字幕の位置・大きさ・色を変えたいときは
`generate_video.py` の上部の定数（`CHROMA` `TEXT_CENTER_Y` `FONT_SIZE`
`SPOKEN_COLOR` など）を触る。フックの文言・大きさ・位置は `HOOK_LINES`
`HOOK_SIZE` `HOOK_CENTER_Y`、フックを見せる間は `generate_narration.py` の
`LEAD_IN` で決まる。

## 冒頭の効果音

音源ファイルは使わず `sfx.py` でその場で合成している（権利関係の心配がない）。

| 時刻 | 音 | ねらい |
| --- | --- | --- |
| 0.00秒 | whoosh（0.30秒） | ノイズのカットオフを上げ下げした「シュッ」。目を引く合図 |
| 0.12秒 | 鈴（りん）の一撃 | 倍音を非整数比で重ねた減衰音。フックが着地する感じを出す |
| 2.65秒 | whoosh（0.22秒） | フックから本文へ切り替わる合図 |

声のピークより約7dB低く混ぜ、最後に全体をまとめて -1.5 dBFS にそろえている
（クリップなし）。音量は `sfx.py` の `WHOOSH_GAIN` `BELL_GAIN` で変えられる。
禅の主題に合うよう、派手なブザーではなく鈴を選んでいる。

## 声の設定

- エンジン: VOICEVOX CORE 0.16.4（ローカル合成。APIキー不要・課金なし）
- 声: **青山龍星「しっとり」**（style_id 84）― 低めで落ち着いた男性の声
- `speedScale` 0.95（ゆっくりめ・間延びしない程度）
- `pitchScale` -0.02（わずかに低く）
- `intonationScale` 0.95（抑揚を抑え、大げさな演技にしない）
- 文と文の間に 0.3〜0.8 秒の無音を置き、語りのテンポを作っている
- 話速は約 6.8 モーラ/秒。美術館・ドキュメンタリーの語りに近い速さ

「宮﨑駿」はOpen JTalkが「みやざきしゅん」と読むため、ユーザー辞書で
「ミヤザキハヤオ」に修正している（`USER_WORDS`）。

## 作り直す

```bash
pip install pillow imageio-ffmpeg numpy   # 動画と効果音に必要
./setup_assets.sh                 # 素材を ./assets に取得（約150MB）
python3 generate_narration.py     # 音声だけ作る（WAV と MP3）
python3 generate_video.py         # 音声・字幕・MP4・WebM を一括で作る
python3 generate_video.py --only alpha   # 透明版だけ作り直す
```

`generate_video.py` は音声を作り直してから、その音声のモーラ長で字幕の
タイミングを決める。音声と映像が同じ計算から出るので、ずれない。
描画は1回で、同じ絵を透明のまま書き出す口と、緑に重ねてから書き出す口の
両方に流している。

`generate_narration.py` の `SCRIPT` が読み上げる文章、その隣の数値が各文の
直後に入れる無音の秒数。`SCRIPT` の1行目がフック。声のトーンは同ファイル上部の定数で調整する。

- `captions.py` … 字幕の区切りと、モーラ長からのタイミング計算
- `sfx.py` … 冒頭の効果音の合成とミックス
- `vvcore.py` … VOICEVOX CORE の C API を ctypes から叩く薄いラッパー
- `setup_assets.sh` … コア / ONNX Runtime / Open JTalk辞書 / 音声モデル / フォント
- `assets/` は容量が大きいためコミットしていない（`.gitignore`）

字幕の文字は **Source Han Sans JP Heavy**（SIL Open Font License 1.1、
商用利用可・クレジット不要）。

MP3の書き出しには `ffmpeg` を使う。入っていない場合は
`pip install imageio-ffmpeg` でも動く（WAVだけなら不要）。
