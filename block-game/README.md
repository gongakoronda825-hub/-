# ブロックの世界（3Dブロックゲーム・初期版）

スマホの横画面で遊ぶ、一人称のボクセルゲーム。移動して、見まわして、ブロックを壊して置く。
それだけです。敵もHPもインベントリもありません。

## 遊ぶ

**https://gongakoronda825-hub.github.io/-/block-game/play/**

インストールも登録も要りません。スマホは横向きにしてください。

配信しているのは `play/index.html` の1枚だけです。外部への通信がまったく無い
（three.js もテクスチャも全部この中）ので、ダウンロードしてオフラインで開いても
同じように動きます。

開発するときは Vite の開発サーバーを使います。

```
npm install
npm run dev      # vite --host。表示された http://192.168.x.x:5173 にスマホからアクセスする
```

実機での確認が前提です。DevTools のモバイルエミュレーションは、マルチタッチの
挙動が実機と違います。

## 操作

| したいこと | 操作 |
|---|---|
| 移動 | 画面左下のスティック（左半分ならどこを触っても効く） |
| 見まわす | 画面右半分をなぞる。上下は ±89° で止まる |
| ジャンプ | 「ジャンプ」を1回タップ。接地しているときだけ跳べる |
| とぶ | 「ジャンプ」を2回連打。もう一度2回連打で解除 |
| 上下（飛行中） | 飛行中だけ現れる ▲ ▼ を押している間 |
| ブロックを選ぶ | 画面下中央のインベントリをタップ |
| こわす | 中央の ＋ を合わせて「こわす」 |
| おく | 面を狙って「おく」。その面の隣に、選んでいるブロックが積まれる |

PC で確認するとき用に、WASD／矢印キーでの移動、マウスドラッグでの視点操作、
スペースでジャンプ、左Shiftで下降、数字キー 1〜3 でブロック選択も受け付けます。

とどく範囲（リーチ）は5ブロック。空を向いていたり遠すぎたりすると、
ボタンを押しても何も起きません。1ブロックの段差はジャンプしなくても歩けば登ります
（足元にブロックを置いても詰まないように）。

飛行中も当たり判定は生きています。壁はすり抜けられません。

## コマンド

| | |
|---|---|
| `npm run dev` | 開発サーバー（`--host` つき） |
| `npm run build` | 型チェック（`tsc --noEmit`）と `dist/` へのビルド |

## 中身

Three.js + TypeScript + Vite。物理エンジンは使わず、当たり判定は自前の AABB です。

```
src/
├── main.ts                      ゲームループ
├── core/config.ts               リーチ・重力・速度などの定数
├── core/Renderer.ts             シーン / カメラ / リサイズ
├── world/blocks.ts              ブロック種別と手続き生成のテクスチャ
├── world/World.ts               ボクセルデータと初期ワールド
├── player/Player.ts             AABB・重力・衝突解決
├── player/FirstPersonCamera.ts  yaw / pitch
├── input/Joystick.ts            移動入力（nipplejs）
├── input/LookControls.ts        視点入力（Pointer Events）
├── input/ActionButtons.ts       ボタン共通の扱いと こわす / おく
├── input/FlightControls.ts      ジャンプ / 飛行の切り替え / ▲▼
├── interaction/BlockInteraction.ts  レイキャストによる破壊・設置
└── ui/                          照準 / インベントリ / 操作説明 / デバッグ表示
```

いくつか、あとから触るときに知っておくとよいこと。

**ワールドは `Map<"x,y,z", BlockType>`。** 固定・小規模なので辞書で十分で、
隣接セルの参照が O(1) になります。ブロック1個につき Three.js の Mesh を1つ持ちます。
レイキャストがそのまま効き、破壊と設置が Mesh の出し入れだけで済むためです。
実機で FPS が落ちるようなら、そのときに結合ジオメトリや `InstancedMesh` を検討します。

**衝突は軸ごとに分離して解きます**（X → Y → Z）。まとめて解くと角で引っかかります。
プレイヤーの `position` は足元の中心で、AABB は 0.6 × 1.8 × 0.6。

**設置は面の法線から隣接セルを求めます。** `face.normal` はローカル座標なので、
ワールド座標へ変換してから使っています。置く前に「既にブロックがある」「自分の体と重なる」
「リーチの外」を弾きます。

**タッチは `pointerId` ごとに追跡します。** 左半分（移動）・右半分（視点）・ボタンが
別々の要素になっているので、3つを同時に操作できます。ボタンは視点ゾーンの子ではなく
兄弟なので、押しても視点は動きません。

**移動と重力はデルタタイムで計算します。** タブから戻ったときに大きく飛んで
壁をすり抜けないよう、1フレームの dt は 0.05 秒で頭打ちにしてあります。

**飛行は重力を切って上下速度を直接与えるだけです。** 慣性は無く、▲▼を離すと
その高さに留まります。衝突解決は歩きと同じものを通るので、飛んでいても壁は抜けません。

**インベントリは種類を選ぶだけです。** 個数も持ち物の増減も扱いません。
`Inventory.current` を `BlockInteraction` が設置のたびに読みます。

## やらないこと

敵 / 動物 / HP / ダメージ / クラフト / アイテムの個数 / 武器 / 昼夜サイクル /
天候 / 自動地形生成 / 無限ワールド / セーブ / マルチプレイ / アカウント / 物理エンジン。

ワールドは自動生成ではなく `buildInitialWorld()` にべた書きしてあります。
