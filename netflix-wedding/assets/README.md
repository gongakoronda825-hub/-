## いまここにあるもの

```

IMG_8432.jpeg   正面を向いている（顔は中央）
IMG_8433.jpeg   伏せて正面向き（顔は左寄り）
IMG_8434.jpeg   伏せて右上を見ている（顔は右寄り）
```

4枚とも横位置（2400×1800）です。これを13スロット全部に使い回しています。

**本編動画（Scene 4）はまだありません。** `main-video.mp4` の名前で置けば入ります。
mp4（H.264）・横位置を推奨します。

4枚とも横位置なので、縦4:5に切り抜かれるプロフィールとローディングは、
`CONFIG` の `pos` で切り抜き位置を顔に寄せています。

### 向きと切り抜きについて

- **プロフィール**は 250×312 の縦枠に切り抜かれます。横位置の写真を入れると左右が切れるので、
  顔が中央から外れている写真は `pos: '70% 45%'` のように寄せてください
  （CSS の `object-position` と同じ書き方です）。
- **背景スライドと More Like This** は 16:9 に切り抜かれます。縦位置の写真を入れると
  上下が大きく切れるため、被写体が下のほうにいる写真は消えてしまいます。横位置を推奨します。
- **背景スライド**は左側にあらすじと再生ボタンが乗ります。被写体が右寄りの写真が向いています。
- スマホで横向きに撮った写真は、ブラウザが Exif の向き情報を見て自動で正しく表示します。
  もし倒れて表示される場合は向き情報が入っていないので、画像アプリで回転させて保存し直してください。

### 写真の大きさ

長辺 2400px 程度に縮めてください。iPhone の写真はそのままだと 5712×4284・1枚6MB ほどあり、
4枚並ぶとブラウザのデコードが重くなって、カーソルの動き出しが 0.7 秒ほど遅れます。
1920×1080 で録画するぶんには 2400px で十分です。

## 別の写真に差し替えるとき

`index.html` 冒頭の `CONFIG` で、各スロットのファイル名を書き換えてください。
スロットごとに別々の写真を使う場合は、下記の名前にすると分かりやすいです。

```
profile-1.jpg 〜 profile-4.jpg   プロフィールアイコン    縦位置（4:5）
loading-thumb.jpg               ローディング中央        縦位置・モノクロ映え
hero-1.jpg 〜 hero-4.jpg        詳細ページ背景スライド  横位置・高解像度
thumb-1.jpg 〜 thumb-4.jpg      More Like This          横位置（16:9）
```

背景スライドは枚数可変です。`CONFIG.detail.heroSlides` の配列を増減すれば、
何枚でも順番にクロスフェードします。

拡張子を変える場合（`.png` や `.heic` など）も `CONFIG` のパスを合わせてください。
