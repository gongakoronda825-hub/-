# assets

ここに写真と動画を置きます。**空のままでも動きます**（グレーのプレースホルダーが出ます）。

下記のファイル名で置けば、そのまま差し替わります。
別のファイル名にしたい場合は `../index.html` 冒頭の `CONFIG` のパスを書き換えてください。

```
profile-1.jpg     yoshito's story      縦位置（4:5）・人物
profile-2.jpg     Chisato's Story      縦位置（4:5）・人物 ← 自動で選択されるプロフィール
profile-3.jpg     Our Story            縦位置（4:5）・人物
profile-4.jpg     How we met           縦位置（4:5）・人物

loading-thumb.jpg ローディング中央     縦位置・モノクロ映えするもの

hero-1.jpg        詳細ページ背景 1     横位置・高解像度（1920×1080 以上）
hero-2.jpg        詳細ページ背景 2
hero-3.jpg        詳細ページ背景 3
hero-4.jpg        詳細ページ背景 4     （枚数は増減可。CONFIG.detail.heroSlides に追記）

thumb-1.jpg       More Like This 1     横位置・16:9
thumb-2.jpg       More Like This 2
thumb-3.jpg       More Like This 3
thumb-4.jpg       More Like This 4

main-video.mp4    本編（Scene 4）      mp4（H.264）・横位置
```

拡張子を変える場合（`.png` や `.webm` など）も `CONFIG` のパスを合わせてください。
