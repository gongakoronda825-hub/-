# assets

ここに写真と動画を置きます。**空のままでも動きます**（グレーのプレースホルダーが出ます）。

## いまの設定：手持ちの写真を使い回す

`index.html` の `CONFIG` は、いま **手持ちの写真を13スロット全部に使い回す**設定です。
下記の名前でここに置けば、全部のスロットが埋まります。

```
photo-1.jpg    椅子で顔をのせている（横）
photo-2.jpg    布団のそばで横になっている（横）
photo-3.jpg    カエルの帽子（縦・顔がはっきり）
photo-4.jpg    ベッドでおすわり（縦・全身）
photo-5.jpg    ソファでおすわり（横・全身）
photo-6.jpg    フィルム風・ビーズクッションで寝ている（縦）
photo-7.jpg    お腹を出して寝ている寄り（横）
photo-8.jpg    部屋の引き・犬は右下（横）
photo-9.jpg    窓の光・部屋の引き（縦）※未使用
photo-10.jpg   窓の光・部屋の引き 明るめ（縦）※未使用

main-video.mp4   本編（Scene 4）・mp4（H.264）・横位置
```

どのスロットにどれが入るかは次のとおりです。

| スロット | 使う写真 | 理由 |
|---|---|---|
| プロフィール1 yoshito's story | photo-3 | 顔がはっきり写っている |
| プロフィール2 Chisato's Story（自動選択） | photo-4 | 全身・おすわり |
| プロフィール3 Our Story | photo-1 | 顔の寄り |
| プロフィール4 How we met | photo-5 | 全身・おすわり |
| ローディング中央 | photo-6 | フィルム風でモノクロ映えする |
| 背景スライド 1〜4 | photo-8 → 2 → 7 → 1 | 横位置のみ。photo-8 は犬が右下なので左の文字と重ならない |
| More Like This 1〜4 | photo-7 / 5 / 8 / 2 | 横位置。隣同士と背景で並びが被らないようにずらしている |

`photo-9` と `photo-10` は互いにほぼ同じ構図で、かつ縦位置の引き（犬が小さく写っている）
のため使っていません。使いたい場合は `CONFIG` のどこかに差し込んでください。

### 向きと切り抜きについて

- **プロフィール**は 250×312 の小さい枠に切り抜かれます。顔が分かる写真が向いています。
  部屋全体の引きの写真だと、犬が小さすぎて何が写っているか分かりません。
- **背景スライドと More Like This** は 16:9 に切り抜かれます。縦位置の写真を入れると
  上下が大きく切れるので、犬が画面の下のほうにいる写真は消えてしまいます。横位置を推奨します。
- **背景スライド**は左側にあらすじと再生ボタンが乗ります。被写体が右寄りの写真が向いています。
- スマホで横向きに撮った写真は、ブラウザが Exif の向き情報を見て自動で正しく表示します。
  もし倒れて表示される場合は向き情報が入っていないので、画像アプリで回転させて保存し直してください。

## 本番の写真に差し替えるとき

`index.html` 冒頭の `CONFIG` で、各スロットのファイル名を書き換えてください。
スロットごとに別々の写真を使う場合は、下記の名前にすると分かりやすいです。

```
profile-1.jpg 〜 profile-4.jpg   プロフィールアイコン    縦位置（4:5）
loading-thumb.jpg               ローディング中央        縦位置・モノクロ映え
hero-1.jpg 〜 hero-4.jpg        詳細ページ背景スライド  横位置・高解像度
thumb-1.jpg 〜 thumb-4.jpg      More Like This          横位置（16:9）
```

背景スライドは枚数可変です。`CONFIG.detail.heroSlides` の配列を増減すれば、
何枚でも順番にクロスフェードします。

拡張子を変える場合（`.png` や `.heic` など）も `CONFIG` のパスを合わせてください。
