# Happy wedding — Netflix風オープニングUI

結婚式のオープニング映像に使う、Netflix風インターフェースのアニメーションです。
ブラウザで開くと**約15秒のアニメーションが自動で1回**流れます。これを画面録画して、
動画編集ソフトで本編とつなぐ想定です。

**写真・動画が1枚も無くても、ラベル付きのプレースホルダーで最後まで再生できます。**
素材は後から `assets/` に入れるだけで差し替わります。

## 構成

```
netflix-wedding/
├── index.html   ← これ1本で完結（HTML / CSS / JS すべて内包・外部依存なし）
└── assets/      ← 後から写真・動画を入れる場所（空でも動く）
```

外部ライブラリ・CDN・Webフォントは一切使っていないので、オフラインでも同じ見た目で動きます。
録画中にネット都合でレイアウトが崩れることはありません。

## 4つのシーン（約15秒）

| # | シーン | 時間 | 内容 |
|---|--------|------|------|
| 1 | プロフィール選択 | 0:00–3.6s | 「Happy wedding」＋4つのプロフィール。偽カーソルが右下枠外から現れ、2番目の「Chisato's Story」をホバー→クリック |
| 2 | ローディング | 3.6–5.0s | 黒転。中央に小さなモノクロのサムネイル＋読み込みサークル |
| 3 | 作品詳細ページ | 5.0–13.0s | 背景に写真のスライドショー、作品ロゴ＋あらすじ3行＋「▶再生 / ＋マイリスト」、上部ナビ、下に More Like This。最後にカーソルが「再生」を押す |
| 4 | 本編再生 | 13.0–15.0s | 本編動画に切り替わり、下部に字幕テロップ |

## 使い方（録画）

1. `index.html` を Chrome で開く（`assets/` は同じ階層に置いたまま）。
2. ウィンドウ／録画範囲を **16:9（推奨 1920×1080）** にする。
3. 画面録画を開始 → **`R` キー**を押す（またはページを開き直す）→ 約15秒待つ → 停止。
4. 書き出した動画を CapCut / DaVinci Resolve などで本編とつなぐ。BGMや効果音は編集時に追加。

- **`R` キー**または**画面クリック（スマホはタップ）**でいつでも最初から再生し直せます。
- `CONFIG.loop = true` にすると自動でループします。

画面は 1920×1080 のデザインを基準に組み、ウィンドウサイズに合わせて自動で拡大縮小します
（16:9 以外の比率では上下または左右が黒帯になります）。

## iPhone / スマホで見る

そのまま Safari で開けます。

- **縦持ち**では画面を90度回転させて、幅いっぱいに表示します。
  画面の向きをロックしていても、横向きの映像として大きく見られます。
- **横持ち**にすると回転が解けて、そのままの向きで表示されます。
- 画面のどこかを**タップ**すると最初から再生し直します。
- 拡大縮小やスクロールは無効にしてあるので、指が当たってもレイアウトはずれません。

回転が不要なら `CONFIG.mobile.autoRotateOnPortrait` を `false` にしてください
（縦持ちでは中央に小さく表示されます）。

本編動画は `muted` + `playsinline` で再生するので iOS でも自動再生されます。
低電力モードで止められた場合に備えて、最初のタップで再生権限を取っておく処理を入れてあります。

### 公開用ファイル

```
node netflix-wedding/build-artifact.js  →  netflix-wedding/dist/artifact.html
```

claude.ai の Artifact として公開するための形（`<!doctype>` や `<head>` を外したもの）を生成します。
URL をスマホで開いて確認する用です。Artifact には `assets/` を同梱できないため、
写真・動画は必ずプレースホルダー表示になります。

## 素材の差し替え

`assets/` に下記のファイル名で置くだけです。ファイル名を変えたい場合は、
`index.html` 冒頭の `CONFIG` にあるパスを書き換えてください。

| ファイル | 個数 | 用途 | 推奨 |
|----------|------|------|------|
| `profile-1.jpg` 〜 `profile-4.jpg` | 4 | プロフィールアイコン | 縦位置（4:5）・人物 |
| `loading-thumb.jpg` | 1 | ローディング中央のサムネ | 縦位置・モノクロ映え |
| `hero-1.jpg` 〜 `hero-4.jpg` | 4（増減可） | 詳細ページ背景スライド | 横位置・高解像度 |
| `thumb-1.jpg` 〜 `thumb-4.jpg` | 4 | More Like This | 横位置（16:9） |
| `main-video.mp4` | 1 | 本編（Scene 4） | mp4（H.264）・横位置 |

文言も同じく `CONFIG` の中です。

- あらすじ … `CONFIG.detail.synopsis`（3行）
- 本編の字幕 … `CONFIG.playback.subtitle`
- タイトル・プロフィール名 … `CONFIG.title` / `CONFIG.profiles`

背景スライドを増やしたいときは `CONFIG.detail.heroSlides` に追記してください。枚数可変で動きます。

## 秒数の調整

タイミングはすべて `CONFIG.timeline` のミリ秒定数だけで決まります（コード中に直書きはありません）。
ここを書き換えれば尺や間を調整できます。

```js
timeline: {
  holdMs:          800,   // 開始待機
  cursorMoveMs:   2000,   // カーソル移動時間
  hoverAtMs:      2800,   // ホバー演出（= holdMs + cursorMoveMs）
  clickAtMs:      3300,   // クリック演出
  loadingStartMs: 3600,   // ローディング開始（黒転）
  loadingDurMs:   1400,   // ローディング表示時間
  detailStartMs:  5000,   // 詳細ページ開始
  playCursorMs:  11500,   // カーソルが「再生」へ移動開始
  playClickMs:   12800,   // 「再生」クリック
  playbackMs:    13000,   // 本編に切替
  endMs:         15000,   // 終了
}
```

`loadingDurMs` は `detailStartMs - loadingStartMs` と一致させてください
（ズレているとブラウザのコンソールに警告が出ます）。

## 注意

- 「Netflix」のロゴやブランドマークそのものは使わず、配色とレイアウトだけを寄せた
  "Netflix風" に留めています（個人利用の範囲で）。
- 参考にした動画の透かし（TikTokロゴ・他人のアカウント名）は入れていません。
  自分の名前を出したい場合は `CONFIG.watermark` を `{ show: true, handle: '@yourname' }` に。
- BGM・効果音は著作権に注意し、フリー音源かオリジナルを使ってください。
- 使う写真・映像は自分たちのものを。
